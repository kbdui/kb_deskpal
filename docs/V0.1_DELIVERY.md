## 端到端验收

- “帮我执行一个任务”创建任务、生成计划并真正执行 echo，返回 Completed 和工具结果。
- 未授权写入返回 Waiting，没有写文件；授权后重新提交生成新任务，中文写入与读取正常。
- 越界路径返回 Failed；失败不会继续执行后续工具。
- Observe / Think / Plan / Act / Reflect 有公开阶段审计，反思只总结实际工具结果。
- 普通聊天不整段保存；成功工具执行保存有界情景摘要，`记住：事实` / `记住:事实` / `记住 事实` 保存语义记忆。
- 正式取消通过 `cancel_task()` 留下状态审计；运行中的工具只能在下一执行边界观察取消。取消、日志故障和记忆故障不会被伪报为成功。

## 已知限制

- 实际 Python 3.11 运行环境不可用；当前实际运行测试为 3.12.4。
- 真实 API 密钥及服务请求未验证，网络协议通过模拟传输测试；默认演示不具有真实模型理解能力。
- Windows 实际符号链接创建因 WinError 1314 跳过，不能据此声称真实链接测试通过。
- Sandbox 仅是可信工具的应用层权限与路径策略，没有完整进程隔离、强制资源限制或不可信插件安全保证。
- 任务是当前进程内状态；记忆和日志持久化。后台调度、抢占取消、自动恢复、向量检索和自动遗忘未实现。
- 规划是一轮有界静态计划，工具步骤不提供事务回滚；原生推理模型多轮工具续接未实现。
- 日志按凭据键脱敏，不记录内部推理；普通文本中的秘密无法自动完整识别。

后续实现应遵循 `ARCHITECTURE.md`、`docs/interfaces.md` 与 `docs/DEVELOPMENT.md`，在现有接口上扩展。
