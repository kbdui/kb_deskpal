# GUI 状态与呈现边界

当前页面以聊天和角色使用为中心，技术 JSON、哈希、长路径和时间戳不作为默认正文。可读摘要与精确原始资料分开，确有需要时允许查看/复制原值。显示成功必须对应实际结果，不能只依据模型回复或请求已受理。

依赖当前记录的编辑、遗忘和处理操作绑定对应记录，未选择时显示明确空态。新建入口与更正入口分开，编辑区域位于侧栏。下拉控件禁用滚轮误改，提供倒三角、悬浮及选中效果；尺寸变化时不能挤出无意义空控件。

页面进入时自动加载；刷新保留有效选择、清除已失效选择。切换档案、隐私清理和关闭让旧回调失效。任务卡区分等待授权、执行中、正在暂停、已暂停及终态，继续不代替确认授权。

实际修改及历史测试范围见[统一实施日志](../reports/implementation-log.md)，P6 仍须完成[整体验收](../planning/companion-redesign/phase-06-delivery/acceptance.md)。
