# GUI 接入

运行 `python -m deskpal.gui --config config.toml` 会由 DesktopLauncher 启动新版清透工作室。主窗口、桌宠聊天、角色档案和模型配置使用 PySide6 的 Qt WebEngine，渲染随软件打包的 `gui/assets/studio/`。CSS 和页面骨架来自确认过的设计稿。Qt 提供原生窗口、文件选择和系统托盘。

`studio_surface.py` 以独立的临时浏览器配置加载本地文档。页面通过 WebChannel 调用明确的桌面动作，资源全部随包提供。页面内容走转义后的纯文本，浏览器配置禁止页面访问本机文件、外部网络及页面跳转。选择图片或归档时由 Qt 提供系统文件选择器，密钥通过维护后台的专用写入通道提交。

`studio_window.py` 将聊天、安排、记忆、工具与插件和设置绑定到真实数据。主窗和桌宠小窗共享聊天状态和任务授权逻辑，各自维护会话选择与滚动记录。执行记录按真实结果和尝试状态形成时间线。切换角色或编辑连接时，Launcher 等待当前 Host 释放后台，再由 `studio_service.py` 打开新样式的档案或配置界面。

验证应同时检查真实页面和数据行为。使用独立临时档案核对聊天、任务授权、只读安排、记忆查询和插件弹层，再对照设计稿检查页签、详情卡片、窄窗和设置层级。Qt 无头渲染和完整 Windows 桌面操作分别记录。旧实现和历史测试的背景见[历史区](../archive/gui-refactor/README.md)。
