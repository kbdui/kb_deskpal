# 2026-11-04 前端体验调整

本次按使用反馈整理聊天、记忆、工具插件、角色设置和桌宠界面。聊天页移除了会跳回最新记录的“刷新”按钮；“加载更早记录”移入聊天记录滚动区顶部；消息更新时改为优先保留阅读位置，发送消息时跟随新内容。新消息入口改为聊天区右下角的圆形下箭头。发送处理中，输入框失焦时提示用户可以继续补充要求，聚焦后不显示占位提示。

聊天消息的头像不再重复显示首字母或称呼。设置的外观页新增用户与角色的聊天显示称呼，默认分别为“你”和“Deskpal”。这些称呼只影响界面显示，不改变角色档案或聊天内容。

记忆页将“更多操作 ···”改为“更多操作”，编辑子页默认隐藏；更正或新建记忆时显示，切回详情或更换记录后隐藏。工具插件页按日程、记忆、角色与互动、文件资料、屏幕工具和通用能力分组，分组可折叠。角色设置用带边框的分组卡片呈现相处方式与当前情绪。

桌宠聊天小窗改为无边框窗口，并移除窗内的收起按钮；桌宠下方的白色状态条已移除，状态保留在悬停提示中，桌宠表情继续承担视觉状态提示。

本次未运行测试，也未做实机界面验证；应用行为和视觉效果仍需在用户环境中确认。
