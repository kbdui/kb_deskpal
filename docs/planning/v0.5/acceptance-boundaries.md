# V0.5 验收边界

日期：2026-10-16。**待开发验收提案，以下均未因本次评估而通过。** 环境、依赖见[评估](environment-assessment.md)，架构与切片见[计划](development-plan.md)。

V0.5 定义为 Windows Qt Widgets 应用层。P0 为权限、隐私、数据完整性与生命周期红线；P1 为本版可用性/交付必需项；P2 为可选扩展。P0 或 P1 未通过只能报告阶段成果，不能宣称完整 V0.5 已交付。

## 自动化与实机证据分层

1. **后端单元/集成**：沿用 V0.4；补非阻塞确认接口、分页/组合快照、幂等/冲突、forget 屏障、关闭竞态。采用合成临时库、fake 慢/失败 provider 和受控工具，无真实用户数据。
2. **Qt 自动化**：pytest-qt 测 queued signal、线程归属、定时器 heartbeat、页面/错误/Busy、双击、乱序、清理失效、启动/关闭；离屏只证明控件和事件逻辑，不能证明系统托盘或真实多屏。
3. **Windows 桌面**：真实交互会话验证 tray 与通知、100/125/150/200% 单屏缩放、至少一组不同 DPI 双屏移动/拔屏、窗口恢复和休眠。若本机设备不足，标记矩阵缺口并在获得设备后补测，不宣称全通过。
4. **安装与长测**：明确 PYTHONPATH/可编辑源码与隔离 wheel 的差别；记录 import 路径和安装版本；最终构建指纹冻结后做 30 分钟。任何修复影响所测路径须重新补对应证据；最终源码改变则重新跑最终长测。

真实 DeepSeek 调用不是 GUI 基础验收前提；如果后续需要验证真实云链路，另列授权、合成文本、次数和 token 上限。旧版一次性授权不延伸到本版。

## 性能与容量门槛（建议值，尚未实测）

以下在阶段 0 探针后冻结；若需调整，须记录机器、原因和新边界，不能测试失败后无说明地降低目标。模型/网络/工具时长与用户等待不计入本地交互延迟。

| 指标 | 建议门槛/测法 |
| --- | --- |
| 容量 | 沿用 1,000 Goals、10,000 Tasks、20,000 attempts、20,000 Proposals，另加 10,000 合成 Memory；分页≤100/批，稳定排序与有界缓存 |
| 本地响应 | 暖态 action→本地页面结果 p95≤300ms，提交/确认测入队回执或可见本地状态，不测最终 LLM/tool 完成；submit/accept 本地段 p95≤200ms；至少100次样本，记录 SQLite 争用与 Busy |
| GUI heartbeat | 50ms timer，慢 LLM/工具期间间隔 p95≤100ms，最大≤500ms；不得用 mock timer 或 processEvents 伪造响应 |
| 取消回执 | 正常 DB 条件下点击→持久 cancel_requested p95≤300ms；DB 争用场景单列 pending/超时，不能阻塞 UI 或冒称调用已停 |
| 启动 | embedding 关闭、缓存已准备的本机冷启动至可交互暂定≤5s；启动中窗口可响应；模型启用单列测量，不承诺同一时限 |
| 空闲 | 关闭 embedding、静态图、无事件 5min；整个 GUI+后端平均 CPU≤2%（单逻辑核100%），暖态后工作集增长≤64MiB；记录绝对 RSS/线程/句柄，绝对内存预算在阶段0实测后冻结 |
| 有界性 | 保持业务队列100；后台请求/回调/视图历史有明确条数和字节上限，查询合并；不按任务无界创建等待线程，不全量载入数据库 |
| 正常退出 | 无活动调用≤5s；阻塞同步工具条件测可响应关闭态、超时保锁与重试，不要求本版强制中止工具 |
| 最终长测 | 最终同构建连续≥1800s、混合负载零非预期业务失败/未处理异常；预期取消、Busy、QueueFull、Conflict、故障注入按预期 outcome 单列，不冒充成功或异常失败；热身后线程/句柄不持续增长、队列/缓存有界；忙时 CPU 与空闲分开报告 |

记录环境、源码/构建指纹、Python/Qt/Windows、冷暖基线、样本数、p95/最大值、monotonic 时长、OS 内存高水位及采样峰值、业务失败数与退出耗时；持久历史正常增长不能冒充缓存泄漏，也不能用平均值掩盖 UI 卡顿。

V0.4 报告是已有后端证据：双 Python 1101 passed/4 skipped、77 strict 文件；其完整 30min 为开发树，最终树 5min 补测不足本门槛。本轮未重跑这些测试，也没有 GUI 性能数据。[V0.4 原始说明](../../versions/v0.4/test-report.md)
