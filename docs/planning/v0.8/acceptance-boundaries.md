# V0.8 验收边界

后续状态：用户已授权[最小T01–T09](../../versions/v0.8/minimal-test-plan.md)，实际测试与未覆盖边界见[测试报告](../../versions/v0.8/test-report.md)；下文保留开工时的拟议门槛，不自行把未测项改成通过。

日期：2026-10-21。状态：待执行；用户要求先开发，完成后先提交测试清单。**本文件没有测试结果。** 开发组织见[开发计划](development-plan.md)。

| ID | 验收主题 | 必须观察的行为 |
| --- | --- | --- |
| P01 | 配置与版本 | 默认关闭；三预设/有限维度校验；bool、NaN、未知字段拒绝；CAS 冲突明确；回退产生新版本；重置不清记忆/任务 |
| P02 | 表达优先级 | 当前明确要求优先；session/today/persistent 有明确期限；cue 到期不解除独立约束；严肃/风险/错误固定中性 |
| P03 | 权限和事实 | 人格设置不入 Planner、不改 Plan/hash/参数/工具风险；Waiting 计划仍按原授权；取消、拒绝、长期离线不惩罚用户 |
| P04 | 出云与调用成本 | 云表达仅有限固定 Persona 预设；本地偏好、cue、affect 不外发；工具路径不增加模型请求，启用风格的普通无工具聊天最多多一次；禁用及管理路径无增量 |
| E01 | 事件与幂等 | 可信最终任务汇总一次；重复、同根来源、确认重试、检索不刷增量；提交失败/Uncertain 不奖励成功 |
| E02 | 动态规则 | 半衰期、状态域、逐事件处理、绝对增量滑动窗与数目上限符合接口；分批/轮询频率不改变同一时刻投影 |
| E03 | 重启与时钟 | 正常离线衰减；时钟回拨/异常跨度回基线；异常恢复不能刷新预算；不重放历史表情和通知 |
| E04 | 重置与遗忘 | reset_epoch/CAS；保留回执和额度；cue 清理；遗忘屏障先重置，旧任务不能恢复已清派生状态；失败仍待清理 |
| E05 | 容量与失败 | 有界回执/窗口/人格历史；容量满拒绝新效果；坏库/未知 schema/写失败不覆盖原库、不重做工具；清理与关闭所有权明确 |
| G01 | 管理面板 | 后台通道，单个在途查询，revision 新鲜度，旧回复/跨隐私 epoch 拒绝；冲突后重载；不覆盖未保存输入 |
| G02 | 静态宠物 | 状态标签始终来自任务；仅允许情境情绪装饰；缺图/关闭/错误/陈旧/隐私屏障回原状态；无重复完成反馈 |
| G03 | 生命周期 | 关宠停止专用请求；关窗/关闭后台遵循原 Host 所有权；旧 generation 不复活窗口/状态；不增加常驻繁忙循环 |
| R01 | 回归 | CLI 离线管理无密钥、GUI/CLI 同数据目录互斥；既有任务/工具/记忆/授权/恢复行为及七字段 presentation 兼容 |

浮点状态在相同 as_of、序列、配置和 reset_epoch 下比较，容差建议 `1e-6`。实际命令、样例、证据位置和执行 Agent 在开发完成后的测试计划冻结。确定性规则、真实 Qt/Windows 行为和真实模型开放文本评审分别记录。
