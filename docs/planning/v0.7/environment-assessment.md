## 1. 结论

采用现有PySide6-Essentials的Qt Widgets/QPainter，在宿主Qt GUI线程绘制有限静态PNG；受控后台线程负责读取/预算预检/QImage解码，GUI只做有界呈现和控制。推荐固定五表情词表的同角色差分，neutral必需；其余缺失回中性图+准确文字。状态文字即时、装饰切图合并/防闪烁，不做序列帧或Live2D动画。

本版无需Cubism SDK/Core、live2d-py、PyOpenGL、WebEngine、独立渲染进程/IPC、建模Editor、CMake/MSVC、CUDA或新推理模型。没有这些组件不构成V0.7静态版缺环境，未来Live2D更新再核验其有效性。

## 3. 技术与线程方案

| 组件 | 使用方式 | 边界 |
| --- | --- | --- |
| QWidget/QPainter | 宿主GUI线程自绘透明图片/中性状态标识 | 不创建动画帧timer，不从工作线程更新Widgets |
| QImageReader/QImage | 后台线程读取已核验的本地PNG；先检格式/尺寸/总像素预算，得到完整图像后交付 | 每reader/文件句柄独占；失败/超量拒绝；解码成功不代表图片美术合格 |
| QPixmap | GUI线程按有限图片/DPR缓存转换与绘制 | 不后台创建；缓存有总量/淘汰，不每次paint重新解码 |
| PetController | 管理代际/加载/显示/状态查询/关停，与DesktopHost协调 | 不持整个Application，不直接写数据库/工具/授权 |
| GuiPreferences/Tray | 独立开关/几何/屏幕/穿透/置顶、恢复入口 | 不存正文/密钥/工具参数，禁用后停专用轮询 |
| importlib.resources/包资源 | 由代码声明的expression_id映射固定PNG，源码和wheel一致 | 不提供外部manifest/路径/URL/脚本输入或自动下载器，未知ID回neutral，无需建设通用不可信资源解析器 |

QImage可交付不表示任意可变图像对象可跨线程共享；结果交付后工作线程不再修改，Qt GUI资源和最终销毁留GUI线程。加载超时失效结果，但worker引用和生命周期必须保留；没有独立进程时不能强杀Python线程来伪造已回收。首版仅可信、大小受控、本地随包静态PNG，遇到异常崩溃或挂起必须归因审查。

只有可恢复的图片加载/绘制失败能中性回退；不能承诺任意Qt/native进程崩溃后主窗口仍存活，也不能把该类故障忽略为无影响。验收使用坏PNG/慢加载注入和实际资源验证正常失败路径，原生崩溃为阻断。

透明图片的alpha与Windows输入穿透分开验证；不能因为背景看不见就假定不挡鼠标。几何保存逻辑坐标，当前DPR用于缩放与命中，多屏可有负坐标/间隙；不沿用只取primaryScreen DPR的做法。

## 5. 初版美术与使用依据

当前流程：角色方向→概念图→同一角色透明PNG定稿→alpha/边缘/比例/缩放检查→入包。Agent可使用内置生图与定向编辑，优先原创角色、不采用未经授权现成角色或私人照片作参考。

适合加入多张静态表情差分，推荐neutral/thinking/focused/pleased/alert五张：中性、思考、专注、克制完成、轻度提示。基于同一neutral定稿定向编辑，优先改眼眉嘴，保持画布/透明边缘/身体/锚点；状态切换不移动或缩放窗口。只有neutral必需，其余缺失回中性并用文字准确区分，取消/拒绝不触发负面惩罚表情。这是宿主状态映射，不是情绪算法，也不调用LLM。

小集合在开启时有界异步准备，切换只查固定映射/已有缓存，不每次解码；必要源图与缩放图按总预算保留，不为五张静态图引入通用外观包框架。没有逐帧动画、拆件PSD、网格/变形器、骨骼绑定、动作导出或.moc3制作任务；后者属于正式版后的更新。

记录生成工具/日期/提示词、参考使用依据、原图/定稿hash、编辑历史、尺寸和用途；AI生成不自动等于排他版权或所有用途许可。保存真alpha，不能用棋盘格/白底冒充透明。定稿资产复制到项目工作区，不只引用工具默认目录；不覆盖用户已有图片。

静态资产预算初值：≤8个PNG、单文件≤5MiB、合计≤20MiB、单图≤2048×2048、总解码像素≤8M；缓存总预算32MiB。尺寸/数量是待初测冻结的项目限制，不是Qt的普适安全保证。编码大小、解码像素、缩放副本和资源峰值分别计量。

本版实际需核查的是图片来源/参考许可、Qt/shiboken与包内通知。当前非商业本机使用不构成所有条款的普遍豁免；未来若发行再核实际分发闭包。Cubism出版/Expandable分类、SDK二进制和模型许可不适用于本版实现，留在[历史Live2D调研](live2d-research-2026-10-19.md)，未来采用时重新核查。
