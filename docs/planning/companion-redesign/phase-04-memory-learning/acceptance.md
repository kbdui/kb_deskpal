# P4 验收：记忆与自学习闭环

状态：2026-10-30 已完成定向隔离自动化；最终合并去重 332 passed／1 skipped，30 文件 strict 通过，证据及场景覆盖见[实施记录](implementation.md)。下列语义与原生实机效果仍须独立核对，不把固定模型返回当作真实理解效果。依赖 P1–P3，对应[开发文档](development.md)。

## 必验场景

| 编号 | 场景 | 合格标准与证据 |
|---|---|---|
| P4-01 | 明确保存、普通推测、假设表达 | 明确保存有实际记录；普通推测入统一缓冲；“如果搬去上海”不变成现住上海。 |
| P4-02 | 查看缓冲结构和重启 | 只有确认的五项业务内容及必要技术元数据，简单真实引用存在，重启可继续，不出现独立偏好池。 |
| P4-03 | 疲惫时少建议，后续解释只是昨天 | 模型修正理解、理由和范围，关联新消息；不要求用户接受／拒绝，不建支持反驳图。 |
| P4-04 | 同一内容反复提及与重复回调 | 合并或更新，不逐句新增重复记忆；同一工作只落一次。模型重复总结不增加证据。 |
| P4-05 | 重要但长期不确定、已无价值记录 | 前者可长期保留推测，后者可清理；不按固定次数、低分或年龄一刀切。 |
| P4-06 | 同步整理阻塞模型，观察发布顺序 | 回复内容可先形成，但整理完成或重试耗尽后才提交并发布；不与下次聊天并行完成本轮提炼。 |
| P4-07 | 临时超时、配置错误、无可提取内容 | 超时有限重试，配置错误不反复尝试，空结果正常完成；状态区分发起和成功。 |
| P4-08 | 结果落库与完成标记间注入失败、重开 | 原子提交或幂等恢复，无重复缓冲，不重做原工具；永久失败仍能发布实际任务结果。 |
| P4-09 | 模型调用期间修改或遗忘源记录 | 提交时发现修订变化，重看最新含义或拒绝失效结果，旧理解不覆盖新要求。 |
| P4-10 | 清空来源会话后查看长期记忆与新摘要 | 会话正文和摘要消失，已形成长期记忆保留，引用标明不可用；旧回调不重新填回会话。 |
| P4-11 | 明确遗忘后重启、复核、旧结果晚到 | 管理接口成功，相关缓冲和派生影响不恢复；旧工作不借重试重建被遗忘内容。 |
| P4-12 | 换说法查询、同档案跨会话、缺失事实 | 能召回相关信息，未知允许不知道；另一个档案不可见，不全量发送数据库。 |
| P4-13 | “以前北京、现在杭州”及否定反例 | 正确区分时段和主体，旧硬过滤不排除必要反例；相似度不被当真实概率。 |
| P4-14 | 超近期窗口的讨论生成并更新摘要 | 目标、已决定和未决项保留，建议不升级事实；更正后旧摘要不继续误导。 |
| P4-15 | 用户说疲惫，工具成功或失败 | 用户状态与角色模拟反应分开；情绪有四项记录，不按成败固定增减。 |
| P4-16 | 同一终态事件重复投递 | 情绪和习惯只采用一次，旧 `CompanionEffects` 固定计算未再重复运行。 |
| P4-17 | 一次临时要求、随后明确长期要求 | 前者只影响对应范围；后者形成适用习惯，并在下一轮规划和表达输入中可见。 |
| P4-18 | 多次有意义反馈后的局部成长 | 学习记录有来源与改变，身份不任意改写，不每轮重写角色卡；行为变化与记录相符。 |
| P4-19 | 连接失败或系统内部模型故障 | 不解释为用户负面反馈，不凭空生新情绪；使用有效旧状态或中性表现并说明实际失败。 |
| P4-20 | 多次查询时间、日程与一次重要共同准备 | 查询明细留执行账本，不新增多条人生经历；有意义互动可形成有来源情景记忆。 |
| P4-21 | 主动整理调用反馈接口，不发布消息 | 可完成合并、修正或遗忘，未生成聊天不算失败，不重新执行来源任务。 |

## 语义与召回效果

真实模型场景至少涵盖同义改写、假设、时间变化、临时／长期、反馈指向、重要不确定和错误推测纠正。每例记录期望、实际、来源、模型及必要调用次数；可以接受不同自然措辞，不接受相反事实或范围。

检索评估既看应召回，也看不应召回：他档案内容、已明确遗忘内容和过期要求不得进入；没有结果时不能编造。记录实际候选与上下文，不只比较向量分数。效果不足则修正提炼／召回流程，不能仅降低门槛让全部记忆进入。

回归参考：`tests/unit/memory/test_memory.py`、`tests/unit/conversation/test_context_and_model_gateway.py`、`tests/integration/agent/test_feedback_learning.py`、`tests/integration/agent/test_role_context.py`、`tests/integration/storage/test_schema_migration.py` 及既有检索夹具。旧预设和规则情绪测试已按新版契约退役，清理依据见[整理记录](../../../maintenance/2026-10-30-repository-cleanup.md)。

退出条件：持久缓冲、修订、去重、清空与遗忘区分、同步收尾、有限重试及实际采用均通过。真实模型效果、召回和界面证据分开报告。出现遗忘恢复、静默删除长期记忆、重复工具、人格跳变无依据或旧新情绪双写，阻断交付。
