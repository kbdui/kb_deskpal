## 口径更新

最新用户决定为：旧版四库及其 WAL/SHM/journal、受管头像/桌宠资源和执行记录不迁移，首次初始化时删除；新建独立 UUID 默认档案。连接配置、凭据引用、workspace、模型缓存和 profiles 子目录保留；存在新版注册信息时不得重复清理。`acceptance.md` 的 P1-01/P1-10 已按此更新。测试不得接触真实数据，只用临时目录和合成内容。

## 验证项

| 验收项 | 最小机制验证（临时数据、离线模型） | 实机验证 |
|---|---|---|
| P1-01 首次初始化 | 临时旧根中放入四库、sidecar、assets、execution log 及共用配置/cache/workspace；首次初始化只清理约定的旧角色数据并创建一个 UUID 默认档案；再次初始化不清理新版档案。检查无模型调用。 | 空闲安装首次启动、重启；确认入口和数据目录状态，确认旧角色数据清理提示/行为符合最新决定。 |
| P1-02 新建 B 隔离 | A/B 各写不同合成事实、聊天、日程、学习标记；检查服务配置实际指向不同四库/资源根，B 不含 A 标记。 | 建立 B 后逐页查看，并确认目录路径属于 B。 |
| P1-03 A→B→A | 检查选择服务实际目录、后台关闭/打开顺序及重新打开后的隔离数据。 | 切换来回并重启；确认当前角色与显示记录一致。 |
| P1-04 延迟调用切换 | 可控阻塞模型替身；旧后台未关闭时切换不得启动 B，释放后旧结果不得写入 B；失败时返回关闭失败。 | 延迟请求中切换，观察关闭中/失败状态及恢复。 |
| P1-05 打开失败 | 损坏 B 的临时数据库或注入初始化异常；确认不运行半初始化后台，未完成创建／导入可见但禁止打开，可重试或删除，A 内容未变。 | 选择损坏档案，确认回到选择入口并可重试。 |
| P1-06 改名 | 改名前后比较稳定 profile_id、目录及合成记录；名称不得参与路径构造。 | 改名后重开并定位原记录/任务。 |
| P1-07 固定会话 | 每档案验证固定日常会话唯一且不能单独删除；专项会话清理不删固定会话。 | 检查固定入口及专项会话清空行为。 |
| P1-08 删除运行中 A | 可控后台确认先关闭、锁释放后仅移除 A 角色数据/受管资源；B、共享 workspace/cache 和外部路径哨兵不变。 | 删除运行中的 A，确认交互、资源清理及 B 可继续使用。 |
| P1-09 备份恢复 | A 合成档案备份后改动再恢复；校验四库、受管资源清单、A/B 隔离及无密钥明文。 | 使用合成档案备份恢复，检查图片资源与清单。 |
| P1-10 中途失败恢复 | 注入迁移/恢复各阶段失败并再次打开；检查恢复标记阻止运行，源内容/可恢复副本保留，未声称成功。旧数据首次清理不适用快照恢复要求。 | 在合成档案故障演练中确认失败提示和重试路径。 |
| P1-11 提醒停用 | 用临时时间源/调度器推进停用期；确认停用无通知、重启后只记录逾期状态、不补弹、不重放已执行副作用。 | 停用期间到期后重新激活，确认提醒呈现。 |
| P1-12 锁与维护互斥 | 同一应用根最多一套角色后台；即使不同档案也不能并行激活。档案级锁保护独立维护，进程退出释放锁。 | 重复启动、跨档案并行激活及并行维护均正确拒绝，关闭后可恢复。 |
