## 准备

使用临时根目录、档案 A/B、合成头像及桌宠资源。A 写入独特标记的记忆、聊天、日程、执行记录；B 使用不同标记。模型用可阻塞、可延迟返回的替身，不调用真实接口。备份与迁移使用合成旧版数据库副本。

## 必验场景

| 编号 | 操作与故障注入 | 合格标准 |
|---|---|---|
| P1-01 | 首次打开含旧数据的合成目录，再次初始化 | 旧四库、配套与受管资源按清单清除，产生全新独立默认档案，无迁移快照或旧记录继承；共用配置／缓存／工作区保留，再次进入不清理新版数据、不复制默认档案。 |
| P1-02 | 新建 B，查看各页面和库路径 | 没有 A 的事实、聊天、日程和学习记录；实际使用 B 的数据库，不只是界面隐藏。 |
| P1-03 | A→B→A，含后台重启 | 各自记录和资源恢复正确，只有当前档案的后台与调度运行。 |
| P1-04 | 旧模型调用延迟、关闭尚未完成时切换 | 不提前打开 B；旧结果不进入 B。明确呈现关闭中或失败，界面不假报成功。 |
| P1-05 | 打开 B 时数据库损坏或初始化失败 | 不运行半初始化后台，能回到选择入口并重试；A 不被覆盖。 |
| P1-06 | 改名 A，再打开、定位旧任务 | 稳定标识和数据引用不变，显示名称更新，原记录不丢失。 |
| P1-07 | 固定日常聊天与专项会话 | 每档案仅一个固定入口，禁止单独删除；专项会话独立，清空不会删除固定入口。 |
| P1-08 | 删除运行中的 A | 先关闭；只清除 A 的全部角色数据及受管资源，B 和外部工作区不受影响。 |
| P1-09 | 备份 A，修改后恢复；包含受管图片 | 清单准确，恢复完整且不改 B；无密钥明文进入包或回执。 |
| P1-10 | 首次清理初始化或备份恢复中途失败，再重开 | 初始化可重入、不误删共用文件或新版档案；备份恢复保持原有可恢复边界，未完成标记阻止半恢复后台启动。旧数据不保留是用户明确决定。 |
| P1-11 | A 的提醒在停用期间到期，再激活 | 停用期间无通知；恢复按逾期状态处理，不集中补弹，已执行操作不重放。 |
| P1-12 | 同一档案再次开实例或并行进入维护 | 原实例锁与维护互斥仍有效；不得出现同库两套执行者。 |
