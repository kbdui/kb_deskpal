# P1 开发记录与待测范围

日期：2026-10-29。状态：**Phase 01 代码与获准的定向隔离自动化已完成，原生实机未验收**。用户已明确开始测试，由 6 Luna 高执行，父 Agent 审查失败与修补代码。P2–P6 没有自动开始。

## 实现范围

- 新增档案注册和管理服务，稳定 UUID 目录，支持创建、改名、选择、删除、备份及导入为新档案。
- 工厂锁定应用根及当前档案，后台只使用当前角色的四库和受管图片；共用连接、凭据、工作区及模型缓存不随角色复制或改写。
- 首次新版初始化按用户最后指令清除旧角色数据，不迁移、不保留快照；固定清理清单和路径检查保护共用资源、稳定锁与新版档案。开发期间没有对用户实际目录执行清理。
- 每个档案初始化自己的固定日常聊天。改名不改身份；缺库、损坏状态、未完成创建／恢复／删除阻止正常打开。
- 档案窗口通过后台维护 worker 执行文件和数据库操作；切换严格等旧 Host 完成后台、桌宠和小窗资源关闭，再等档案 worker 停止后重开新 Host。
- 打开失败可以回档案选择或共用维护；旧维护离线恢复不再写入应用 `data_dir`，由档案导入接口注册后使用。
- 继续复用现有执行账本恢复和提醒逾期处理，不增加自动回滚、未激活后台或跨档案共享数据层。
