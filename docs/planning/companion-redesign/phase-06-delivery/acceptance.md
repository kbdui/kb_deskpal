## 方法和环境

使用临时档案、合成文档与日程、隔离资源目录。先做机制自动化，再在获准情况下进行真实模型及 Windows 原生交互。真实连接、凭据、输入法、DPI、托盘与系统通知的结果单独记录；离屏 Qt 或模拟结果不能代替。

窗口至少核对小窗、窄主窗、常规主窗与最大化。可采用约 720、1280、1920 像素宽的可用环境；记录实际客户区尺寸和缩放，不把被屏幕约束后的尺寸当作请求尺寸。原生环境不支持的部分标未验证。

## 用户路径

| 编号 | 实际操作 | 合格标准 |
|---|---|---|
| P6-01 | 配置默认云模型后开始聊天；改用设置中的本地连接 | 入口不反复问云／本地，相关背景按说明使用；真实密钥不出回显和日志，本地不是固定命令演示。 |
| P6-02 | 编辑开放角色卡，跨页和重启后继续 | 设置集中，无六轴／旧模式平行编辑入口；实际规划和表达使用已保存卡。 |
| P6-03 | Enter、Shift+Enter、中文输入法确认候选 | 发送与换行正确；输入法候选确认不误发；消息跨页保留。 |
| P6-04 | 桌宠小窗打开、发送、收到回复、展开主窗 | 进入当前档案日常聊天，双向内容一致；小窗无执行详情按钮，主窗右侧栏可查实际执行。 |
| P6-05 | 询问当前无日程、查询失败及部分成功 | 模型组织自然语言，空结果按查询范围表达；失败不说“没有日程”，不贴长工具 JSON。 |
| P6-06 | 查询文件、读取、总结并建提醒 | 每一步依据真实结果，必要许可在流程中明确可见；不要求用户自行找另页确认再回来，任务原会话不消失。 |
| P6-07 | 运行中追加要求，随后取消或另行请求回撤 | 登记与实际采用状态清楚，遵守下次判断时机；取消保留已完成操作，回撤是新任务。 |
| P6-08 | 新建专项会话，跨会话询问事实；一个会话倾诉另一个处理任务 | 同档案记忆可召回，临时互动范围不串；固定日常入口不可单独删。 |
| P6-09 | 更正记忆、清空聊天、明确遗忘，分别重启 | 更正有效；清空只影响会话与工作上下文，长期记忆仍在；明确遗忘后不被摘要、缓冲或旧学习恢复。 |
| P6-10 | 切换档案并观察日程、小窗、头像和回执 | 无旧档案数据／图片／消息残留，未激活后台停止；切回数据和有效状态正确恢复。 |
| P6-11 | 删除当前档案、导入备份、恢复失败再重试 | 先关闭后台，删除只影响目标档案；恢复完整、失败可重试，不自动重放外部操作。 |
| P6-12 | 记忆页、安排页、工具页切换和持续滚动，打开下拉再选择 | 无滚轮崩溃、无意改选、收尾闪烁或首次必须重载才有内容；条目和详情易读。 |
| P6-13 | 窄屏、普通和宽屏查看输入、筛选与右侧栏 | 无无意义小框、遮挡或超长条；下拉箭头、悬浮、右键菜单和空选择状态一致。 |
| P6-14 | “今天别主动找我”，再暂停提醒和恢复 | 快捷入口与聊天使用相同策略，实际外发按范围控制；普通学习不产生待审批列表。 |
| P6-15 | 学习临时失败、耗尽重试、模型故障 | 不无限等待、不丢实际工具结果；可读反馈不暴露内部协议或秘密，不伪装为学习成功。 |
| P6-16 | 重启、关闭、托盘退出及切换失败 | 各资源可靠关闭，旧模型结果不写新后台，错误可恢复；无残留调度不断提醒。 |
| P6-17 | 多步任务请求暂停、追加要求、继续；暂停后重启再查看 | 主窗／小窗区分“正在暂停”和“已暂停”；下次模型判断前实际暂停并释放执行线程，重启不自动续跑。明确恢复后沿原任务结合最新状态与要求继续，不重放已完成操作或绕过授权；与通知暂停及取消入口含义明确。 |

## 完整语义验收

至少覆盖：方案指代、长对话续接、同义记忆召回、时间变化、假设不入事实、临时与长期区别、角色影响规划、反馈纠错、情绪来源、主动安静、自动整理不要求发消息。使用不同自然表述复核，不通过关键词固定模板伪造智能。

每例写模型／连接类型、输入、可访问的合成背景、期望、实际结果与数据依据。不同措辞、建议次序可接受；越权、串档案、错误事实或假报操作成功不可接受。未获准真实模型时只报告机制结果。

参考现有 `tests/gui/chat/test_chat_refactor.py`、`test_pet_refactor.py`、`test_management_regressions.py`、`test_management_readability.py`、`test_readable_task_cards.py`、`test_readable_settings.py`、`test_bridge.py`、`test_host_faults.py` 和维护／资源相关覆盖。

**阻断完整交付的情况**：错档案读写、数据丢失或无法恢复、重复副作用、未经许可执行、假报成功、遗忘恢复或清空误删长期记忆、窗口崩溃／死锁、越过通知暂停、秘密泄露。核心语义场景失败不得仅标为“界面已完成”。
