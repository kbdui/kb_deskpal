# Phase 06 最小实机清单

日期：2026-10-31。以下为待验证项目，优先使用临时角色与临时工作区。自动化范围及尚未解决的环境限制见[实施记录](implementation.md)，本文没有勾选任何尚未实际执行的原生或真实模型场景。

1. **配置并真正聊天**：在设置编辑云模型地址、模型名和密钥，保存并重新打开后台；密钥不回显。确认角色卡生效，普通回复和工具查询均由真实模型组织语言；查询失败不能说成“没有日程”。本地模型仅在需要时从设置切换。
2. **会话与输入**：Enter 发送、Shift+Enter 换行，中文输入法确认候选不误发。新建专项会话，跨页后消息与草稿还在；日常聊天入口固定。主窗和桌宠小窗对话一致，小窗展开主窗定位正确，没有执行详情按钮。
3. **任务闭环**：在临时工作区安排一次需要许可的写入，再做多步任务；在聊天原地核对准确对象与确认，侧栏查看真实结果。运行时追加要求、暂停、继续，确认已经完成的步骤不重放；取消不声称自动撤销。合成规划器的真实文件写入已通过隔离自动化，本项仍需验证实际模型与交互链。
4. **记忆与安排**：查看三个记忆分组和学习记录；右键／更多操作更正、遗忘，新建不会误改旧记录。遇到版本变化，草稿保留，核对后明确采用新版本。日程时间易读，目标与关联可创建和编辑；后续关注与确定提醒区分，结束关注不误称取消已执行操作。
5. **角色和形象**：从设置管理角色，切换前后台安全关闭，切换后没有旧消息、图片、日程或回执残留。上传头像与静态桌宠图片，预览、应用、恢复默认正确。清空聊天保留长期记忆与固定入口；备份和恢复按现有完整档案流程操作。
6. **窗口和滚动**：在窄窗、普通窗和宽屏切换五页，反复滚动记忆／工具／安排，展开下拉并悬浮、选择。滚轮不误改选项，没有空小框或闪烁；窄窗详情可返回列表。分别验证浅色、深色、Windows 拖动、缩放、最大化、贴靠、125%–200% 缩放及跨屏恢复。
7. **桌宠、托盘和通知**：点击桌宠和托盘打开小窗，右键调整大小或进入通知设置；关闭到托盘后可唤回，退出后后台实际停止。“暂停主动聊天”和“暂停约定提醒”作用正确，恢复不会补弹一串旧提醒。约定提醒仍按实际安排履约。

记录实际窗口尺寸、缩放、模型和每项结果；失败时保留最短操作顺序、可见现象和相关任务记录。不要只记录“窗口正常”或把离线演示当作真实模型验收。
