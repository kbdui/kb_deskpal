# P6 开发：界面收口与整体交付

日期：2026-10-29；2026-10-31 更新。状态：代码与定向自动化完成，尚未完成真实模型与原生整体验收。依赖 P1–P5；对应[验收文档](acceptance.md)。用户已确认新版设计及入口调整，采用 QFluentWidgets / PySide6 统一窗口骨架和组件；完整设计见[新版界面方案](interface-design.md)。角色切换只在设置，桌宠小窗通过桌宠或托盘打开，两者均不增加导航项。实际变更与验证结果见[实施记录](implementation.md)，待验证路径见[最小实机清单](minimal-manual-checklist.md)。

## 目标与范围

以聊天为中心重建清楚、易用的界面，让全部用户入口使用新版后台，清除旧设置、状态和候选审核流程。主窗口优先 FluentWindow；通用控件统一复用组件库，桌宠透明窗口保留专用行为。汇总迁移、真实模型、实机和恢复证据，不以交互预览或单个模块测试代替整条链路完成。

重点入口：`gui/chat.py`、`pet_chat.py`、`window.py`、`management.py`、`settings.py`、`catalog.py`、`task_card.py`、`tool_results.py`，Bridge、Host、DesktopFacade 和维护界面。旧 `persona_settings.py` 和 `interaction_state.py` 已于 2026-10-30 清除；实际文件拆分按职责决定，不为符合文档增加空包装。

## 页面和交互要求

| 入口 | 交付行为 |
|---|---|
| 档案选择 | 可创建、改名、切换、删除及备份恢复；切换显示真实关闭／打开状态。每档案自己的日常聊天固定，当前档案标识清楚。 |
| 聊天 | 以“聊天”为用词，Enter 发送、Shift+Enter 换行；消息和任务状态不因页面切换消失。运行中追加要求提供明确关联当前任务的入口。 |
| 桌宠小窗 | 默认进入当前档案日常聊天，可输入和查看回复、展开主窗；遵守现有小窗不显示执行详情按钮的约定。切换档案不残留旧对话。 |
| 执行记录 | 主窗口右侧栏查看，聊天用自然语言说明实际结果，不铺开工具参数、JSON、路径或内部调用号。 |
| 记忆 | 易读查看事实、经历和必要状态；缓冲不是人工候选待办，不再要求逐条接受／拒绝。保留记忆新建、修改、遗忘的管理能力与无选择时的合理空状态。 |
| 安排 | 日程、任务和提醒使用当前档案真实状态，取消与暂停含义分清，必要许可在当前操作链就地呈现，完成后回到原上下文。 |
| 设置 | 人格和其他设置集中；开放角色卡取代三预设／六轴滑杆，旧短时模式与独立偏好候选审批移除。人格、学习默认工作，不靠默认关闭回避问题。 |
| 连接和资源 | 默认云连接，本地连接在设置中可选。密钥沿现有安全服务保存与后端使用，不回显秘密。保留用户上传静态头像／桌宠图片及当前档案资源归属。 |
| 工具插件目录 | 当前可用工具、用途与状态可查看，保留后续扩展界面和接口；不把没有隔离能力的第三方任意代码标为已安全支持。 |

继续沿用已有记录级右键操作、紧凑下拉三角和悬浮效果；避免滚轮在未有意编辑时改变选项。不同窗口宽度下筛选框、输入框、详情栏保持可读，不能挤成无内容的复选框或空条。

## 调用与状态收口

1. 对 Bridge／Facade／CLI／维护入口做调用清单，将旧字段和动作迁入对应服务，不让旧页继续写状态。
2. 界面回执绑定档案与后台代次、会话、操作；页面导航不会丢掉已受理修改，切换档案后旧回执作废。
3. 多轮任务展示当前阶段、已完成部分、等待许可／补充或取消状态。追加要求登记和模型已采用是两种状态，不能说登记成功就是已经改变了当前操作。
4. 同步记忆整理等待期间给出简短处理状态，不把学习过程或内部协议作为聊天正文。学习失败最终允许回复实际结果，不能无限转圈。
5. 原始技术细节放入已有详情入口，默认使用名称、简短时间和可理解结果；完整路径与准确原始信息按需查看，不用截断文本冒充完整值。
6. 备份恢复及删除范围说明与 P1/P4 一致；清空聊天不遗忘，取消不自动回滚。需要许可时向用户展示实际目标，不增加普通学习审核。

## 开发步骤

先审阅新版界面方案，验证 PySide6、QFluentWidgets 与无边框窗口依赖组合并锁定版本，再建立页面到新版接口映射。按统一壳与聊天、任务与详情、记忆和安排、设置及资源、工具目录和小窗顺序替换视图；再检查主小窗切换、窄屏、缩放、多屏和滚动生命周期，最后完成跨模块全流程和恢复场景。模型连接表单集中后仍复用现有维护与凭据服务，补齐必要的安全重开后台编排，不以普通 settings DTO 直接写密钥。

P2–P5 已通过的服务、协调器与业务契约继续复用，视图可以按新设计整体替换，不因旧页面已能运行而保留不合适的布局。代码清理确认无活跃调用方再删除，不能顺带删掉权限、来源、托盘和后台生命周期控制或任务执行账本。旧版本文档保留原文，当前用户与开发指南更新实际能力和未决项。
