# 用户自行检查：GUI 实机操作要点

2026-10-26。按用户要求，实机交互由用户后续自行测试；**下表全部未验证**。自动化结果见[测试记录](test-report.md)，不能代替以下视觉、输入法、焦点和系统行为。

建议先用独立测试配置、测试会话和可丢弃文件，避免用重要记录验证清空、删除和覆盖。使用项目 GUI 环境启动 `python -m deskpal.gui --config <测试配置路径>`。首次配置和真实模型连接方法见[快速开始](../../user-guide/quick-start.md)与[配置说明](../../user-guide/configuration.md)。离线演示是固定命令规则，不能用于评价人格表达或自然语言理解。

| 编号 | 你可以怎样操作 | 应看到什么 | 状态 |
| --- | --- | --- | --- |
| M01 导航与视觉 | 依次切换聊天、安排、记忆、工具插件、设置；缩窄窗口、增大系统字体，查看长中文与路径 | 会话栏只在聊天出现；其他页使用完整主区；主要操作不裁切，文字/焦点/禁用状态可辨；设置入口集中 | 未验证 |
| M02 会话与记录 | 在日常聊天和两个专项会话中分别发送测试消息，切页、小窗展开、退出后重开 | 消息归属正确且存档保留；日常聊天不可改名、归档或删除；清空测试记录仍保留日常入口；专项上下文独立 | 未验证 |
| M03 输入与草稿 | 主窗和小窗输入中文，确认输入法候选；尝试 Enter、Shift+Enter；切会话、两窗编辑同一会话 | 输入法确认不误发送；Enter发送、Shift+Enter换行；共享草稿不串会话，发送回执不覆盖后续新输入 | 未验证 |
| M04 滚轮与键盘 | 在设置各分区把鼠标放在下拉、数字框、滑条上滚动；展开下拉列表；再用点击/键盘选值 | 滚轮滚页面，不误改值；展开列表可滚动查看但不自动提交选择；点击和键盘仍可明确修改 | 未验证 |
| M05 原地审核 | 对测试文件或提醒发起需授权的操作；审核参数后确认；切页返回，同时在两窗查看 | 原会话有可理解的完整范围；普通/高风险授权分明；“已受理”和“已完成”区分；不会要求绕到隐藏页面；终态不残留确认框 | 未验证 |
| M06 桌宠与双窗 | 启用桌宠，单击、拖动、右键、隐藏再显示；小窗输入/查看回复/展开；设置内调整60%–160% | 点击与拖动不混淆；右键只有窗口动作；小窗可聚焦且不出屏；重开默认日常聊天，展开定位同会话；图像大小与命中区域一致 | 未验证 |
| M07 图片同步 | 在设置分别导入用户头像、角色头像、桌宠主图及一张差分；预览后应用、快速换图、重置单槽并重开 | 主窗/小窗相应头像同步；桌宠正确换图；旧图片迟到不覆盖新图；缺差分使用当前主图；失败保留原图，各槽互不覆盖 | 未验证 |
| M08 设置与模型 | 只从设置调整人格/表达和模型；检查未配置状态，保存连接后生效；如需本地，明确切换本地服务 | 聊天/桌宠/工具目录没有另一套配置；未配置能浏览但不发送；保存和当前生效状态明确；密钥不回显明文；本地模式不隐式回退云 | 未验证 |
| M09 提醒与工具 | 创建短时间测试提醒，查看当前安排和到期收件箱；关闭系统通知、重开后查看错过项；浏览工具目录 | 确认/结果回原会话；关闭系统通知仍有应用内提醒；退出期间不假称准时通知；工具名称/权限真实，查看不执行工具 | 未验证 |
| M10 系统与退出 | 跨不同DPI屏幕移动桌宠/窗口，检查屏幕边缘；有草稿时尝试退出或进入维护；启用关窗留托盘后关闭并恢复 | 无离屏/命中错位；穿透时可通过托盘打开主窗进入设置恢复；退出有未保存提示；留托盘不丢草稿；维护切换等待旧资源关闭 | 未验证 |

M06/M10 的多屏、拔屏、托盘和通知取决于实际设备与 Windows 状态；没有做的子项继续记未验证。睡眠/唤醒可作为 M09/M10 的补充，观察错过提醒与重新定位，不改变系统安全设置。

若使用明确的离线演示，`echo 测试聊天` 可验证命令回复；`tool timer_create {"duration_seconds":10,"label":"测试提醒"}` 可验证提醒审核与到期流程。请按实际卡片范围确认；这些例子不代表真实模型的自然语言或人格效果。

发现问题时记录编号、操作顺序、实际表现、是否稳定复现；截图前遮蔽个人内容和密钥。分别记通过、失败、未做及设备限制，不能用单个成功操作推定整行所有子项通过。
