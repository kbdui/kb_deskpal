## 已确定的方向

| 事项 | 本次设计采用的结果 |
| --- | --- |
| 定位 | 围绕人格模拟、日常聊天和个人桌宠 Agent，办事能力自然出现在聊天中 |
| 风格 | 用户选择的暖白、柔和配色、圆角卡片；沿用原生 PySide6，统一视觉组件 |
| 名称 | 主入口称“聊天”，默认会话称“日常聊天”；“陪伴”只描述产品定位，不作页面名称 |
| 导航 | 聊天、安排、记忆、工具插件、设置；会话栏仅在聊天页存在 |
| 会话 | 日常聊天固定且不能删除/归档；专项会话独立上下文，共享人格及允许共享的长期记忆 |
| 数据清理 | 默认会话身份保留，记录可清空；长期记忆可单独遗忘，清理反馈按真实影响范围显示 |
| 桌宠 | 单击附近小窗，默认日常聊天，可切专项；展开定位同一会话；右键仅窗口动作 |
| 设置 | 所有配置集中设置页，聊天头像、工具目录、记忆页、桌宠和托盘不另设配置快捷入口 |
| 模型 | 新安装默认云，只有设置内可切本地；旧用户显式选择和旧数据用途不被改写 |
| 凭据 | 设置密码框经专用后台通道交系统凭据库；配置仅存引用，不回显原密钥；保存与生效分别反馈 |
| 图片 | 设置中本地导入用户/角色头像和静态桌宠形象，预览后保存；不上传模型服务 |
| 工具 | 独立目录显示真实已注册能力和权限；保留扩展协议，不承诺已有第三方插件市场 |
| 输入 | Enter 发送、Shift+Enter 换行，保护中文输入法；滚轮滚页面，不改选项 |
| 授权 | 原会话展示真实计划、确认和结果；受理不等于执行成功，终态不残留确认控件 |

初始窗口尺寸、间距、颜色数值、缩放档位等是设计建议，不是用户逐项确认的约束。现有信息足以完成本次文档，无需重复询问已确认的偏好。

## 为什么必须改后端

| 用户可见结果 | 必需后端支持 | 验收入口 |
| --- | --- | --- |
| 切页、重启不丢会话 | 持久目录与时间线、一致提交、有界上下文、默认会话保护 | G01、G02、G06、G07 |
| 确认后有明确结果 | 结构化审核、当前权限投影、命令受理查询、按任务更新 | G03–G05 |
| 创建提醒后能收到提醒 | 调度事件收件箱、去重游标、来源复核、会话关联 | G11 |
| 设置保存可靠 | 分区版本冲突处理、独立维护生命周期、保存/生效状态 | G12、G17、G18 |
| 图片重启及恢复后仍可用 | 受控导入、素材元数据、原子发布、备份格式演进 | G19、G20 |
| 工具列表可信且可扩展 | 真实工具注册表投影、可用状态、版本与配置能力接口 | G21 |

界面重排不能替代这些改动。技术方案继续保留单实例、唯一执行器、工具沙箱、来源与用途限制；小窗不会启动第二个 Agent，存档和凭据配置也不会自动授予工具执行权。
