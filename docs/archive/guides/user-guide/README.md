# Deskpal 用户指南

适用代码版本：`0.5.0rc1`，随 2026-10-26 GUI 重构源码更新。此次 D1–D5 范围见[开发记录](../../gui-refactor/development-status.md)，自动化结果与实机未验证边界见[测试记录](../../gui-refactor/test-report.md)。

Deskpal 是围绕人格模拟与日常聊天构建的 Windows 桌宠 Agent，提供图形界面、命令行和受控工具。新安装默认云连接，在设置配置后使用；也可切换真实本机端点或明确使用固定命令离线演示。本地 BGE 独立用于记忆语义检索。当前仍是候选版，真实模型体验和物理桌面边界保留待验收事项。

## 当前能力与限制

- 会话目录、聊天、任务、记忆与目标在本地保存，原始上下文按会话隔离；日常聊天固定不可删除，历史浏览与模型近期预算分开。
- 云连接保存后普通新输入按已保存的默认用途处理；旧来源与类别限制仍有效，相关配置只在设置中调整。
- 写文件、创建计时器等需要普通确认；移动、删除文档需要独立高风险确认。
- 主动提议、人格/模拟情绪、桌宠和系统通知默认关闭，按需启用。
- 当前工作区的 BGE 语义检索已启用，模型在 `data/models/bge-small-zh-v1.5`，使用项目 `deskpal_env` 加载；内置默认仍关闭，权重和本地配置不随 Git 分发。使用与校验见[数据维护](../../../user-guide/maintenance.md)，聊天模型另行配置。
- 同一数据目录仅允许一个 GUI 或 CLI 实例。当前同步调用使用协作取消，操作系统隔离、强制停止、细粒度授权、无人值守执行和 Live2D 仍属后续范围。

版本目录里的 `v0.7/v0.8/v0.9` 是增量工作资料分类，软件包版本仍为 `0.5.0rc1`。验收范围可查阅[产品化测试记录](../../releases/v0.9/test-report.md)、[拟人化测试记录](../../releases/v0.8/humanization-test-report.md)和[静态桌宠交付说明](../../releases/v0.7/delivery.md)。旧版操作说明中的功能限制可能已被后续代码更新，本指南按当前实现组织。
