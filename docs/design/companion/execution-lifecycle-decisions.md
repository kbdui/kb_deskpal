# 执行与生命周期：已采纳决定

整理日期：2026-10-30。本文为辅助摘要，不替代完整设计约定，原文已恢复到[29 日十项确认结论](../../planning/companion-model/2026-10-29-redesign-follow-up-decisions.md)。后续明确纠正见下文，详细开发与验收见[六阶段目录](../../planning/companion-redesign/README.md)。

1. **上下文与检索。** 规划阶段提供双方交流、当前决定、助手建议和真实工具结果，明确其来源与不确定性。角色卡、有效要求按范围准备；相关长期记忆采用有预算的词法/语义检索，必要时模型补查，摘要追踪真实来源。相似度不代表真实性。
2. **统一操作。** 复用模型工具机制，补齐记忆、人格要求、任务、通知和主动关注的内部管理接口。用户说过的调整必须由服务实际落实，不能只口头答应；不增加聊天前的语义规则快捷绕过。后续快速路径单独设计。
3. **多轮执行。** 请求绑定档案和会话→准备上下文→模型决定下一步→程序检查权限与参数→执行并保存真实结果→交回模型继续判断。2026-10-30 用户纠正：所有面向用户的聊天回复均经过表达润色，普通聊天的规划结果也是草稿；此前“不强制第二次润色”的记录有误。无工具不等于省略表达阶段；主动决定安静不生成回复。润色不得篡改事实、操作状态或授权。多轮调用、重试和工具重做分别记账，已完成副作用不重放，未知结果不盲目重试。
4. **追加要求。** 通过独立入口登记到当前任务，在下次模型判断采用；错过当前判断则等下一次。已决定的一组步骤允许完成，不提供逐工具抢占，不另启第二个 Agent。范围变化仍要重新落实权限。
5. **手动暂停。** 立即持久记录请求，在下次模型判断前变为 Paused 并释放执行线程。当前调用和步骤组可完成；若先正常结束则如实报告终态。继续同一任务时读取最新有效状态及追加要求，累计预算不重置，已完成操作不重放，继续不等于授权。重启后保持暂停，不自行续跑；取消后不可继续。
6. **同步学习与重试。** 生成最终回复→自动记忆评估并保存缓冲→提交任务并发布回复。暂不做异步学习或自动让位。任务发起与完成分开登记，模型临时失败有限重试；不因发起过一次就永久认定成功，也不无限阻塞回复。学习记录有来源、归属与修订检查。
7. **档案与会话。** 全部角色业务数据隔离；关闭旧后台后再启动新后台。各会话临时要求按自身范围生效，长期记忆在同档案共享。缓冲建模与新版长期内容对接，理由由模型维护，原消息关联由程序保存。
8. **清理和取消。** 清空聊天只清该会话内容与工作上下文，不动长期记忆。遗忘复用记忆管理接口；删除角色清理完整档案。取消日程/任务由对应工具执行，必要时确认。取消不撤销已完成操作，需要回撤时另请模型帮助，不要求所有工具实现通用撤销或强制中断。
9. **主动行为。** 应用层独立协调模块支持可增删的触发方法。事件、安排复查、交流机会和低频整理只提供检查机会；是否联系、怎样联系交给模型。普通主动聊天也经唯一 Dispatcher→AgentCore；纯内部整理经同一 Dispatcher→反馈学习。工具范围和用户授权由程序控制。确定提醒走原调度，不依赖模型批准；静默不伪造用户消息。
10. **配套与验收。** 统一模型网关与预算、严格协议、逐轮不可变计划及步骤账本、来源修订、准确授权和可恢复状态同步调整。阶段顺序为档案基础→角色上下文→多轮工具→反馈记忆→主动行为和暂停→界面与整体验收。不得用旧通过数或离线响应证明真实模型和实机效果。

聊天里的通知要求通过策略服务落地，主动聊天与提醒可分别暂停，与任务暂停无关。内部整理不发消息，已有工作不自动让位。未激活档案没有后台。以上不是新增无限自动操作权限，必要的工作区与危险操作边界保留。


2026-10-30 后续确认：多轮授权、暂停与重启后保持有效长期记忆和工作上下文；后台复查触发与执行复用同一冻结批次并公平覆盖。模型可为任何值得维护的事项安排 internal 复查或 chat 交流，包括情绪；内部复查走 Dispatcher→反馈学习，普通主动交流仍走 Dispatcher→AgentCore。完整决定见[补充确认](../../planning/companion-model/2026-10-29-redesign-follow-up-decisions.md#十一2026-10-30-补充确认任务上下文统一复查与情绪变化)。
