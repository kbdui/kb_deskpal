# 人格与记忆：已采纳决定

整理日期：2026-10-30。本文为辅助摘要，不替代完整设计约定。原文已恢复到[28 日重设计讨论](../../planning/companion-model/2026-10-28-character-memory-redesign-discussion.md)和[29 日确认结论](../../planning/companion-model/2026-10-29-redesign-follow-up-decisions.md)；后续补充见下文，实施进度见[阶段目录](../../planning/companion-redesign/README.md)。

## 角色与数据

每个角色有唯一、连续的人格和记忆，支持备份，不提供人格版本切换器。角色切换采用完整档案：人格、记忆、所有会话、任务、工具记录、日程与学习记录全部隔离。早期“日程和工具共享”的提议已被替代。只有连接、密钥、外部工作区与模型缓存共用；头像与桌宠受管资源属于角色。

切换前关闭旧后台，再启动新后台。未激活角色不执行任务、整理或提醒；重新激活时核对过期工作，不补发所有积压通知，不重做未知操作。旧版开发数据按用户决定清理初始化，不作为必须迁移保留的人格资料；此决定不授权未来任意删除用户数据。

## 人格与五层含义

人格是开放角色卡与模型逐步学到的相处习惯。默认工作，角色卡参与理解问题、选择建议、组织思路和最终表达。前端不提供三个预设、六条表达轴或人格版本列表让用户频繁调整。学习和语义判断由模型承担，程序负责范围、来源、保存、预算和有效性。

| 层次 | 含义 |
|---|---|
| 长期人格 | 角色惯常怎样思考、相处，变化慢且保留学习记录 |
| 当前情绪 | 对眼前事件的模拟反应，有事件含义、来源、强弱和延续范围 |
| 对用户状态的理解 | 用户明确说出的需要或模型暂时推测的状态，推测仍标为不确定 |
| 当前互动方式 | 当下先倾听、讨论或协作等方式，关联会话和期限 |
| 表达调节 | 最终语气、篇幅、玩笑与表现的具体调节，可受前述层次联动 |

撤掉旧的独立互动状态模型：会话约定、短时 cue、偏好候选等不再分别建一套业务状态。用户可在聊天中提出“今天少开玩笑”“先让我倾诉”等要求，由模型理解并通过对应管理接口保存到合适范围。六轴如保留为内部表现参数，也不等同于情绪本身。旧版按工具成功/失败增减数值情绪的规则不作为新模型。

当前情绪保留四项记录：情绪描述与强度、原因及真实来源、发生时间与预计持续范围、不确定程度。可以同时存在复杂反应，不强制固定情绪词或把用户状态直接复制成角色情绪。程序负责去重、时间经过后的减弱与有效性，模型不可用时沿用仍有效状态或中性表现，不重新启用按工具成败计分。情绪影响关注与表达，明确请求和实际事实仍优先；没有回应不自动解释为拒绝。长期习惯只作有根据的局部更新，不每轮重写角色身份，也不把模型自己的重复总结当作新证据。

## 记忆、工作上下文与缓冲

长期内容按事实与知识、情景理解等新版用途管理；不为五个旧枚举强造五套功能。当前正在讨论与处理的事情归入会话工作上下文，含双方交流、决定、助手建议、未解决事项和有来源的摘要，不另建永久记忆类别。同一角色的各会话可按相关性检索长期记忆，临时要求仍限定自身范围。

工具调用参数、逐步输出和状态属于任务账本，页面按任务/时间归组。模型可从一次经历中提炼值得长期保留的意义，但不把每次查时间或空日程都作为单条长期情景记忆。列表与正文用自然语言和清楚标签，原始字段只在明确查看技术详情时呈现。

不确定理解进入统一缓冲区，保留内容、所属用途、状态、模型理由及必要复查/清理安排；允许长期保持不确定，不硬性强迫立即接受或删除。理由由模型写，原消息、任务、会话及修订的真实关联由程序保存。不建立复杂支持/反驳关系图，也不恢复独立人工偏好候选待办。

缓冲的五项业务内容为：当前理解、预期去向、来源／理由、不确定性与适用范围、整理状态与时间。用户明确要求且内容清楚的保存或更正，经模型判断后可以直接落实，不要求全部先进入缓冲。丢弃一条推测不等于删除原始聊天；明确遗忘则连同相应缓冲和派生内容检查失效。内容保留多久与执行任务是否成功是两种不同状态。

模型主动或被动二次复核后可采用、修订、保留、合并或归档；有限确信度、矛盾与变化由模型理解，不靠固定语义规则决定。被更正、删除或失效的来源不能通过摘要和检索复活。长期人格学习记录应保留；具体表与接口以[数据库设计](../../planning/companion-redesign/database-design.md)和 P4 为准。

2026-10-30 补充决定：普通记忆更正先更新原记录，已形成的人格习惯、情绪及其他理解由后续模型学习逐步纠偏，不要求程序准确枚举并立即重写所有“相关”派生理解。更完整的派生关联复核放入[正式版后优化](../../roadmap/post-release.md)。这不撤销明确遗忘、来源外发限制、当前执行所需修订检查，也不允许旧摘要覆盖已经更正的原记录。

## 模型连接与边界

默认云模型，本地连接在设置内选择，主业务通过统一模型接口处理。正常人格和自动学习不因初期复杂类别许可而默认关闭；高级云端数据许可延后。旧资料已有的 `local_only` 等来源约束仍应尊重，凭据保护和危险操作授权继续有效。延后复杂系统不意味着可以把受限来源直接发出。
