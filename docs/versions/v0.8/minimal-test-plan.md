执行已完成，结果与限制见[测试报告](test-report.md)。新增文件最终采用不同basename，兼容默认pytest收集：`tests/unit/test_v08_companion_runtime.py`、`tests/integration/test_v08_companion_integration.py`、`tests/gui/test_v08_companion_gui.py`。所有数据用tmp_path、显式environ、注入时钟、录制LLM和独立QSettings，不读真实配置/密钥/用户数据库，不调用真实API。T07必须区分生产入口的Busy拒绝与已受理的隐私屏障，不能绕门禁后声称生产并发遗忘成功。
