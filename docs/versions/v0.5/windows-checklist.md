该冒烟由程序驱动窗口，不证明用户点中了真实托盘菜单、不证明 Windows 展示了通知，也没有改变系统缩放、锁屏或执行休眠。自动化的缺托盘、动态托盘消失、quiet/DST 与窗口边界测试另见[测试报告](test-report.md)。

## 手工步骤与记录

托盘/通知优先在项目环境运行 `python scripts/check_gui_manual.py`，使用独立临时数据、工作区和 QSettings；保持工具授权未选，完成后从托盘退出。默认关窗另用 `--default-close --output data/validation/v05/gui-default-close-session.json`。脚本不修改系统设置，输出只表示可观测事件，OS 展示必须由执行人确认。真实云链路另行授权；切换缩放前保存其他应用工作。
