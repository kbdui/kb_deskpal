# V0.7 静态桌宠运行说明

更新：2026-10-21。按用户要求带未决项[归档](delivery.md)，未全部验收通过，产品版本仍0.5.0rc1。Live2D延期至正式版后更新，V0.6保持暂停。

## 使用

沿用现有GUI安装和启动方式，不新增SDK、OpenGL、图片生成服务或运行时下载器。默认不启用桌宠；主窗口设置中“启用静态桌宠”打开。显示开关只隐藏窗口，保留启用状态与有限缓存；禁用释放窗口、缓存并停专用查询。主窗口和托盘都可开关显示、置顶、整窗鼠标穿透；穿透后在主窗口设置或托盘取消即可恢复交互。

单击角色打开主窗口，拖动移动并保存独立位置；不确认任务、自动授权或执行工具。桌宠变化不主动抢焦点。位置以Qt逻辑坐标保存，显示器变化时夹回可用工作区；真实混合DPI和鼠标穿透的通过范围以测试报告为准。

主窗口关闭仍沿用现有关闭到托盘设置；关闭桌宠不终止后台任务。退出应用由宿主统一关闭后台和图片线程。看到Closing时等待真实释放；不重复启动同数据目录实例或强杀线程来掩盖挂起。

## 状态与故障

中文状态文字来自权威任务元数据。空闲、待处理、规划、执行、等待确认、完成、失败、取消、需要审查、结果待确认均有区分；查询过期/失败显示“状态未知”。通知开关不控制桌宠状态。图片表情只是固定展示映射，不是人格/情绪算法；Failed不代表已回滚副作用。

素材缺失、损坏或加载超时会退到中性图片或项目标记，tooltip包含有限分类诊断（例如neutral:missing、assets:timeout、paint:failed），不输出正文或私有路径。正常PNG、美术效果与降级路径分开验收。重新禁用再启用可发起新一代加载；旧结果不会复活已关闭窗口。

第一次打开旧schema1大任务历史时，会在后台启动期间补齐三个索引；不存在UI主线程建索引或每秒重建。合成10万历史初测建索引约0.8秒，这是本机单次证据，不能保证所有数据库同样耗时。

## 本地验收工具

只使用新的合成临时AppConfig/QSettings，不读取真实.env、私人配置、数据库或封存V0.6对象。全部命令显式用项目解释器；工具输出必须保存到新的data/validation/v07目录，不能覆盖首败。

- `scripts/check_v07_asset.py --preview <新的诊断目录>`：PNG/alpha/hash/预算及棋盘预览；结构通过不等于视觉通过。
- `scripts/check_v07_projection.py --output <新的JSON路径>`：自建并保留合成历史库、索引计划和锁响应，不接受现有数据库路径。
- `scripts/check_v07_pet.py --mode smoke`：真实随包PNG与合成后端；默认offscreen，不能据此认证Windows透明输入。
- `--slow-core-seconds 4` 与 `--slow-loader-seconds 4` 分别执行两条独立慢路径，不能合并替代。
- `--native --mode soak`：同构建30分钟原生运行，包含有限预热、禁宠/启宠各5分钟热空闲和20轮循环；对照运行与指标判定由父审查。
- 资源探针使用单个非Qt后台线程每秒采样，只记录本进程指标；GUI读取有时间/年龄标记的有界最新样本，不能将过期或缺样当作正常值。启宠/禁宠对照均包含同一个诊断采样线程，原始记录见resource-worker.jsonl；退出后该线程也须真实结束。五图循环预览明确标记test-only，不代表后台执行到了对应任务状态。
- `scripts/check_v07_pet_input.py --seconds 600`：专用合成原生底窗/控制台，供实际鼠标点击、拖动、穿透和DPI观察，最长10分钟后正常关闭；不注入鼠标、不全桌面读屏或挂全局钩子。
- `scripts/check_v07_distribution.py --wheel <本次wheel> --installed-dir <独立target> --cli-python <无Qt解释器> --output-dir <新目录>`：比对随包资源并从明确target隔离执行CLI帮助；不安装依赖、不认证完整CLI业务。安装GUI另用具备项目依赖的解释器运行`check_v07_pet.py --installed`并核对source_package确实来自target。

开发期间内置image_gen只生成随包PNG，不属于用户运行依赖。来源/提示词在[素材记录](../../../src/deskpal/gui/assets/pet/provenance.json)。当前只评非商业本机使用，未来分发前仍需复核实际素材和Qt等依赖条件。

`check_v07_preview_trace.py`和`check_v07_resource_retention.py`是归档保留的未验证诊断草稿，不列入上述已测工具。前者类型修正未复检、后者未完成源审/strict；本轮按用户要求未执行，后续先审查再安排，见[后续测试清单](deferred-tests.md)。冻结长测探针会保留原始计时/样本列表，运行中进程内存包含测量成本，不能据此独立认证产品无泄漏。
