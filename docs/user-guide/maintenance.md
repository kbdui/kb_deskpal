# 数据维护

维护前关闭使用同一数据目录的 GUI/CLI，等待后台与数据库安全释放。通过设置中的维护入口或 CLI maintenance 查看诊断、配置、缓存和备份恢复；以实际回执为准，不能把“请求受理”当作完成。

角色业务库和受管图片属于档案，模型连接、凭据、外部工作区与缓存共用。备份时核对清单、哈希及包含的数据库和图片，不假定密钥也已导出。恢复会检查格式、版本与目标，发生部分失败时按提示处理，禁止手动拼接或覆盖数据库假装恢复完成。

普通缓存验证只核对已有资产，不需要重新下载模型。模型下载与真实 CPU 推理是另外的显式操作；不要把当前正在使用的缓存目录当作诊断脚本的新临时 root。新克隆没有本地权重，准备方法见[Embedding 指南](../developer-guide/embedding-setup.md)。

清空聊天、遗忘、删除角色含义不同，见[记忆与隐私](memory-and-privacy.md)。用户自行导出的外部备份不随应用内遗忘自动删除。真实配置、密钥、数据库、日志和模型文件不应提交 Git。

旧版维护命令和测试证据保存在[历史指南](../archive/guides/user-guide/maintenance.md)，其 schema 和测试路径可能已变化，不直接作为当前执行脚本。
