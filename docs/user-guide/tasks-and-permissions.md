# 任务、授权与执行记录

模型理解请求后可以先查资料或执行一步，再看实际结果决定后续步骤。查询不到日程时应直接告诉你当前没有安排；长参数和工具明细放在主窗口右侧执行栏，不占据主要回复。

需要许可的操作在原任务内等待，核对操作内容与范围后再确认。普通许可与危险操作许可分别处理。模型说“完成”不能代替实际状态，授权只适用于对应计划，继续任务也不等于同意新的操作。

追加要求会在下一次模型判断时纳入；如果刚好错过本次判断，已经决定的一组步骤可以继续。暂停同样不强行中断当前调用或步骤组，到下次模型判断前进入“已暂停”；此时释放执行线程。点击继续后沿原任务结合最新情况判断，已完成操作不重做，预算不重置。

取消停止后续工作，不自动撤销已经写入或发出的操作。需要回撤时可以另请模型帮助，仍受相应权限约束。结果不明时系统应如实说明，不通过盲目重试冒充成功。

重启后暂停任务保持暂停，等待授权任务也不自动执行。清空聊天、遗忘来源或切换角色后，旧计划需重新检查有效性。主动任务同样受工具范围和授权限制，主动聊天暂停与任务暂停是独立功能。
