# 排错

无法发送时先在设置检查模型连接、模型名和凭据是否保存生效。缺配置不会自动变成离线智能；离线演示只处理有限固定命令。不要把真实密钥粘入问题反馈、聊天或日志截图。

任务未完成时查看实际状态：等待授权需先核对计划；正在暂停要等下一次模型判断边界；已暂停需手动继续；取消不会撤销已完成操作。模型文本与执行事实不一致时，以任务和步骤记录定位问题，保留原始失败信息，不反复确认同一副作用。

页面无内容或选择丢失时可重新加载并记录页面、操作顺序及状态。Qt offscreen 测试不能排除真实滚动、尺寸变化和桌面生命周期问题。反馈尽量提供可复现顺序与脱敏截图。

启动或切换提示占用时，等待原应用完全退出，不直接删除实例锁或正在使用的库。维护失败按回执检查目标与恢复状态，不用手工覆盖数据库绕过错误。缓存缺失时区分缺依赖、缺资产和未启用，不默认重新下载。

当前全量自动化仍有待复核失败，详见[整理记录](../maintenance/2026-10-30-repository-cleanup.md)；历史通过数不能证明本次所有功能已通过。
