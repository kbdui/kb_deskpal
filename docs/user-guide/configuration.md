# 配置与模型连接

模型连接在“设置”集中配置：服务、地址、模型名和 API 密钥。默认云模型，确实需要本地模型时切换连接；聊天不逐条询问云或本地。缺少可用模型配置时明确提示，不生成假的智能回复。固定离线演示只用于有限流程验证。

密钥由界面提交给后端配置维护流程，展示使用掩码；系统支持时可选系统凭据存储。不要把密钥写进角色卡、记忆或聊天。密钥与连接在角色之间共用，不随着角色数据库复制。备份是否包含什么以归档清单为准，不能假定导出自动包含可用密钥。

人格使用开放角色卡与模型学习，默认参与理解和回复。设置可以维护角色身份与形象，但不提供旧版三预设、六轴或偏好候选审查流程。短时相处要求可在聊天中直接提出，由后台保存到适用范围。

角色业务数据与受管头像/桌宠图片隔离；连接、工作区和模型缓存共用。界面可选择静态图片并由后端导入受管资源，原始文件路径不作为可随意修改的数据库资源。Live2D 尚未交付。

使用远程模型时，回答所需的相关上下文会交给该服务。完整逐类云端许可属于后续方向；已有来源的本地限制和必要工具授权继续有效。不要将“不再提供繁杂设置”理解成可以发送密钥或违反已有来源约束。

安装和字段样例参考仓库 config.example.toml；维护见[数据维护](maintenance.md)，本地语义检索见[准备指南](../developer-guide/embedding-setup.md)。
2026-11-01 表达协议：`llm.expression_output_format="prompt"` 表示最终回复直接使用自然语言正文，不强制套 JSON；`json_object` 才使用接口原生 JSON 输出并严格解析回复外壳。两种模式都会经过模型润色，且不能发起工具或越过真实结果、学习回执及隐私约束。规划、记忆和人格更新等内部结构化协议不因最终表达模式而改变。

记忆评估默认输出上限8192、超时40秒，显式配置仍优先。真实反馈被截断会按失败处理，不能视作记忆保存成功；更低预算可能不适合需要较长推理的连接。反馈仍在回复发布前同步完成，复杂请求可能等待较久。代码更新后重启应用／后台生效，不会自动改写你的配置文件。
