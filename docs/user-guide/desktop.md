# 桌面、角色与聊天

主窗口分聊天、安排、记忆、工具插件和设置。人格、连接及形象设置集中管理；工具页查看当前注册能力，不代表已经支持任意第三方插件安装。技术原值放在明确的详情入口，平时阅读自然语言摘要。

每个角色都有固定“日常聊天”入口，不能删除入口，可以清空聊天。还可新建专项会话，同一角色共用长期人格与记忆，各会话保留自己的聊天背景。回车发送，Shift+回车换行。聊天提出的临时要求只在相应范围生效。

点击聊天顶部的会话名称可选择或管理会话，离开聊天后目录自动收起。安排页分日程、任务和后续关注；目标与分步计划在任务内。日程默认显示接下来的安排，也可查看历史；“在聊天中修改或取消”只准备草稿，由你发送后再执行。记忆页按“记住的内容、一起经历、仍待明确”阅读，右键或详情中的更多操作可更正、遗忘；“学习记录”查看最近的整理依据，不需要逐条批准。

点击桌宠可打开旁边的小对话窗，默认进入日常聊天，也可切换专项会话；右键提供快捷操作，主窗口设置桌宠大小与静态形象。小窗聚焦输入、回复与任务确认，不显示执行技术详情按钮；完整执行记录在主窗口右侧栏查看。

切换角色时整个业务档案切换，后台先安全关闭再启动；未激活角色不提醒、不整理和不执行任务。角色间不共用聊天、日程或工具账本，但模型连接和外部工作区共用。已经产生的外部文件操作不会因切换自动撤回。

角色切换在“设置 → 数据与隐私 → 管理角色档案”，不放在导航栏。模型连接与 API 密钥从“设置 → 模型连接”编辑，旧后台安全关闭后进入设置表单；密钥默认保存到系统凭据库，保存后重新打开后台生效。桌宠小窗也可从托盘打开，通知与免打扰集中在设置。

进行中的任务可追加要求、暂停或取消，具体生效边界见[任务](tasks-and-permissions.md)。关闭时等待当前调用返回和资源释放，不能把窗口消失等同于后台已经安全停止。原生桌面表现仍须按 P6 单独验收。
