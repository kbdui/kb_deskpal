# 桌面界面与聊天

2026-10-26 GUI 重构源码版；开发范围见[本轮记录](../planning/gui-refactor/development-status.md)，自动化结果见[测试记录](../planning/gui-refactor/test-report.md)。实机交互仍待用户按[操作要点](../planning/gui-refactor/manual-checklist.md)自行检查，历史测试结论不覆盖新界面。

启动：`python -m deskpal.gui --config config.toml`。完成首次配置的方法见[快速开始](quick-start.md)。

## 请求、会话与管理页面

| 区域 | 日常操作 |
| --- | --- |
| 聊天 | 日常聊天、专项会话、消息与原地任务确认；Enter 发送，Shift+Enter 换行 |
| 安排 | 待确认、提醒与日程、进行中和历史；目标与建议为二级区域 |
| 记忆页 | 显式记住、审核候选、更正和遗忘 |
| 工具插件 | 查看真实已注册能力、用途、版本、权限与可用原因 |
| 设置 | 人格与表达、桌宠外观、通知、隐私、模型、工具配置及维护 |

固定“日常聊天”只有一个，不能删除、归档或改名；可在设置的隐私分区清空内容。专项会话支持命名、归档、恢复和删除。会话目录和消息持久保存，切换页面、关闭窗口和重启不删除存档；升级前从未存储的旧完整聊天无法恢复。会话栏只在聊天页显示，其他页使用完整内容宽度。

人格与允许共享的长期记忆在会话间共用，原始聊天上下文各自独立。模型每次仍只读取预算内的有效近期记录（默认最多 8 轮 / 16 KiB），历史可查看不代表全部进入模型。草稿仅在本次进程内保留，关闭到托盘不会丢；退出前请处理未发送内容。

发送后先显示正在发送，持久受理后跟踪原任务。需要确认的操作在原会话展示完整审核卡，确认受理和执行成功分别反馈，终态不保留授权控件；安排页也可查看同一任务。普通聊天以消息与回复呈现。列表默认每页 50 条，后端单页上限 100 条。

## 互动设置与候选

角色身份、人格、表达偏好候选、临时覆盖和云类别许可全部位于“设置 → 人格与表达”；聊天没有另一组配置入口。称呼与语言候选仍作为记忆内容在记忆页审核。聊天中“这次简短一点”可作为本次请求意图，不等于修改全局配置。

云模型用途许可分为自定义人格、偏好、历史情境线索、模拟情绪、当前会话历史，默认关闭。允许某一类别后，仍须满足请求用途和该内容来源的用途限制。确认偏好不会授权任何工具。

## 人格与模拟情绪

人格和模拟情绪默认关闭。可使用 `balanced`、`warm`、`concise` 预设；自定义风格为正式、温暖、幽默、详略、表现力、好奇六个 0..1 数值。它们调整表达和有限表现，不改变任务事实或工具权限。

显式偏好可选 `session/today/persistent`，分别表示本次运行、配置时区当天、持久设置。当天偏好在当地下一午夜结束。短时情境 cue 为 `neutral/supportive/focused`，最长 1800 秒；会话偏好和 cue 不跨重启保存。

风险确认、失败、取消、待复核仍使用中性文字。表达调用失败会回退并提示，不能据风格回复推定工具成功。真实模型的拟人化体验仍有[暂缓问题](../versions/v0.8/hm08-deferred-issues.md)。

## 静态桌宠

设置中启用桌宠后，单击角色打开附近的小聊天窗，重新打开默认进入“日常聊天”，也可切换专项会话；展开时主窗口定位同一会话。小窗共用消息、草稿与审核组件。拖动超过系统阈值才移动，不会松开后误触点击。

大小（60%–160%）、置顶、穿透、显示和图片都在设置内调整，滚轮不修改选项。右键仅提供聊天、打开主窗口、收起小窗、暂时隐藏等窗口动作。开启穿透后可从托盘打开主窗口，再进入设置恢复。禁用释放桌宠资源；隐藏不删除会话或取消任务，单击角色本身不授予权限。

“设置 → 桌宠与外观”可本地导入用户头像、角色头像、桌宠主图与可选差分，支持静态 PNG/JPEG，单图最多 5 MiB、单边最多 2048 像素。校验并预览后应用，原文件不变，不上传模型；缺少自定义差分时使用自定义主图。JPEG 不自动去背景。

任务状态文字优先于图片表情。查询失败/过期显示状态未知；素材缺失时降级到中性图片或项目标记。可禁用后重新启用触发新一轮素材加载。当前是静态 PNG 表现层，Live2D 尚未接入。

## 托盘、通知和退出

默认关窗退出；启用“关窗留托盘”且托盘可用时，关窗隐藏，从托盘恢复或退出。系统通知默认关闭，开启后先建立基线，不补发历史通知。安静时段默认按配置时区的 22:00–08:00，可调整。

提醒到期写入应用内收件箱和关联聊天，系统通知是额外渠道；关闭系统通知不删除未读。通知只用通用摘要，点击后重新读取当前来源。退出期间不保证准时提醒，重新启动后可查看错过的提醒。Windows 可能抑制系统通知；退出显示 Closing 时仍在等待后台调用和线程结束，详见[排错](troubleshooting.md)。
