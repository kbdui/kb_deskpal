# 桌面界面与陪伴设置

启动：`python -m deskpal.gui --config config.toml`。完成首次配置的方法见[快速开始](quick-start.md)。

## 请求、会话与管理页面

| 区域 | 日常操作 |
| --- | --- |
| 对话与会话 | 输入请求、选择用途、新建或关闭会话、查看近期对话 |
| 任务页 | 查看原计划和步骤账本、授权、取消、复核历史任务 |
| 记忆页 | 显式记住、审核候选、更正和遗忘 |
| 目标与提议 | 建立目标/里程碑/来源绑定，查看、接受或忽略提议 |
| 设置 | 陪伴风格、桌宠、托盘、通知及配置维护入口 |

选择“独立请求（无会话历史）”时，每次请求独立处理。“新建会话”启用本次运行的有界上下文，最近最多 8 轮 / 16 KiB；关闭会话会清空该上下文，重启不恢复完整聊天档案。**任务记录仍按持久化规则保存**，清空会话不等于删除任务或长期记忆。

提交后的界面 `request_id` 只是桥接回执，不能当作任务已入队或执行完成的证据。需要确认的任务请到任务页核对真实状态。列表采用分页，默认每页 50 条，后端单页上限 100 条。

## 互动设置与候选

会话内“互动设置与偏好候选”支持有限角色身份、明确偏好候选，以及清除短时线索/表达覆盖。回复详略、幽默和追问偏好需要确认后保存；称呼与语言候选到记忆页审核。

云模型用途许可分为自定义人格、偏好、历史情境线索、模拟情绪、当前会话历史，默认关闭。允许某一类别后，仍须满足请求用途和该内容来源的用途限制。确认偏好不会授权任何工具。

## 人格与模拟情绪

人格和模拟情绪默认关闭。可使用 `balanced`、`warm`、`concise` 预设；自定义风格为正式、温暖、幽默、详略、表现力、好奇六个 0..1 数值。它们调整表达和有限表现，不改变任务事实或工具权限。

显式偏好可选 `session/today/persistent`，分别表示本次运行、配置时区当天、持久设置。当天偏好在当地下一午夜结束。短时情境 cue 为 `neutral/supportive/focused`，最长 1800 秒；会话偏好和 cue 不跨重启保存。

风险确认、失败、取消、待复核仍使用中性文字。表达调用失败会回退并提示，不能据风格回复推定工具成功。真实模型的拟人化体验仍有[暂缓问题](../versions/v0.8/hm08-deferred-issues.md)。

## 静态桌宠

设置中启用“静态桌宠”后显示项目内置图片角色。单击角色打开主窗口；拖动可移动并保存位置。主窗口和托盘可切换显示、置顶和整窗鼠标穿透。

鼠标穿透后，到主窗口设置或托盘取消穿透。“隐藏”保留启用状态和有限缓存；“禁用”释放宠物窗口和缓存并停止专用查询。桌宠不拥有任务授权入口，单击不会确认任务。

任务状态文字优先于图片表情。查询失败/过期显示状态未知；素材缺失时降级到中性图片或项目标记。可禁用后重新启用触发新一轮素材加载。当前是静态 PNG 表现层，Live2D 尚未接入。

## 托盘、通知和退出

默认关窗退出；启用“关窗留托盘”且托盘可用时，关窗隐藏，从托盘恢复或退出。系统通知默认关闭，开启后先建立基线，不补发历史通知。安静时段默认按配置时区的 22:00–08:00，可调整。

通知使用通用摘要，点击只打开对应页面重新读取。Windows 可能抑制通知，以窗口当前状态为准。退出显示 `Closing` 时仍在等待后台调用和线程结束，详细处理见[排错](troubleshooting.md)。
