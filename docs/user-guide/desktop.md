# 桌面、角色与聊天

主窗口分聊天、安排、记忆、工具插件和设置。人格、连接及形象设置集中管理；工具页查看当前注册能力，不代表已经支持任意第三方插件安装。技术原值放在明确的详情入口，平时阅读自然语言摘要。

“工具插件”的能力目录可以按提供方筛选。切到“插件”，选中“日程与计时器”并打开页面，可以查看接入插件事件流后的最近到期记录。勾选“仅显示计时器到期记录”后，偏好保存在当前档案中。到期通知和免打扰仍在设置中管理。

每个角色都有固定“日常聊天”入口，不能删除入口，可以清空聊天。还可新建专项会话，同一角色共用长期人格与记忆，各会话保留自己的聊天背景。回车发送，Shift+回车换行。聊天提出的临时要求只在相应范围生效。

任务需要你补充信息时，当前会话只有一项待补充任务，会在输入框上方显示“正在回答”及问题，直接发送即可继续原任务；多项时先选择目标。点击“× 新话题”可另起请求，原任务继续保留。任务卡的“补充信息”会聚焦同一个输入框。主窗口、桌宠小窗和手机网页使用相同规则；问题与补充回答都会保留为聊天记录。重启后仍可续办，发送前任务状态若已变化会保留草稿并要求重新选择。

点击聊天顶部的会话名称可选择或管理会话，离开聊天后目录自动收起。安排页分日程、任务和后续关注；目标与分步计划在任务内。日程默认显示接下来的安排，也可查看历史；“在聊天中修改或取消”只准备草稿，由你发送后再执行。记忆页用于只读查看“记住的内容、一起经历、仍待明确”和学习记录；需要记住、更正或遗忘时在聊天中提出，由统一记忆整理处理并给出实际结果，不需要逐条批准候选。明确要求遗忘且目标清楚时直接处理；不清楚先询问。遗忘仅清除指定提炼记忆，保留聊天原文、其他记忆与人格、执行记录及安排；归档与遗忘不同。

点击桌宠可打开旁边的小对话窗，默认进入日常聊天，也可切换专项会话；右键提供快捷操作，主窗口设置桌宠大小与静态形象。小窗聚焦输入、回复与任务确认，不显示执行技术详情按钮；完整执行记录在主窗口右侧栏查看。

待确认理解分别记录“下次复查”和“最晚归档”时间，由模型判断填写；到期仍未采用时自动归档，保留内容和依据，退出日常检索，不删除聊天原文或相处习惯。采用后清除待确认阶段的归档期限。应用关闭期间到期的记录，下次打开时补处理。

“设置 → 桌宠与外观”可切换普通、思考、专注、愉悦、提示五个表情槽位，每次为当前槽位选择一张静态图片，预览后保存应用。只设置普通形象也可以，未单独配置的表情回退到该形象；没有相应自定义资源时使用内置小机器人。各角色的受管形象与表情独立，新角色默认使用内置资源；聊天头像另行设置。

推荐透明 PNG、1:1 正方形画布、512 × 512 或 1024 × 1024 像素，角色完整居中并留白；各张保持画布、人物大小、位置和脚底基线一致，仅改变表情。非正方形可按比例完整显示。支持静态 PNG/JPEG，每张不超过 5 MiB、宽高不超过 2048 像素，不能全透明，不支持动画或精灵图切帧；五个自定义槽位合计不超过 800 万像素和 20 MiB，整套建议每张不超过 1024 × 1024。JPEG 不支持透明背景。导入在本机完成，该操作不将图片发送给模型。

切换角色时整个业务档案切换，后台先安全关闭再启动；未激活角色不提醒、不整理和不执行任务。角色间不共用聊天、日程或工具账本，但模型连接和外部工作区共用。已经产生的外部文件操作不会因切换自动撤回。

角色切换在“设置 → 数据与隐私 → 管理角色档案”，不放在导航栏。模型连接与 API 密钥从“设置 → 模型连接”编辑，旧后台安全关闭后进入设置表单；密钥默认保存到系统凭据库，保存后重新打开后台生效。桌宠小窗也可从托盘打开，通知与免打扰集中在设置。

进行中的任务可追加要求、暂停或取消，具体生效边界见[任务](tasks-and-permissions.md)。关闭时等待当前调用返回和资源释放，不能把窗口消失等同于后台已经安全停止。原生桌面表现仍须按 P6 单独验收。

QQ 文字私聊/群聊入口在“工具与插件 → 插件 → QQ 聊天”。连接、授权范围、触发思考与实际发送的边界见 [QQ 使用说明](qq-chat.md)。该首版目前只有静态审查记录，未做收发或实机验收。
