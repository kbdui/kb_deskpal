# 记忆与隐私

记忆页主要查看角色长期保留的事实、知识和经历理解，以及模型尚未确认的缓冲内容。当前会话正在讨论的事情属于工作上下文；逐条工具输出属于执行账本，不能把一次查时间当作一条重要长期记忆。

自动学习默认工作。模型提炼的理解可以先保持不确定，再在后续交流或内部复核中采用、修订、合并、继续保留或归档。理由由模型维护，原消息和任务关联由程序保存；不要求你逐条人工处理“偏好候选”。学习失败有限重试，不代表已经保存成功。

列表按可读内容组织，点击记录查看详情；更正、遗忘等依赖当前记录的操作放在相应记录的菜单与右侧编辑区。新建记忆单独提供入口，未选择记录时显示明确空态。兼容资料中出现“候选/接受/拒绝”表示旧记录状态，不是新版自动学习的必经人工流程。

清空聊天只删除该会话内容和工作上下文，不动长期记忆。想删除某件事，可在聊天中提出遗忘，系统通过记忆管理操作落实，并清理相应派生正文；遗忘不等于清空所有聊天或撤销外部操作。删除角色会清理该角色完整档案，用户自行保存的外部备份需自行管理。

同一角色各会话可以检索相关长期内容，不同角色全部业务库隔离。远程模型使用相关上下文时仍尊重已有来源限制；不要将凭据写入记忆。高级云端许可的长期方向见[规划](../roadmap/post-release.md)。
