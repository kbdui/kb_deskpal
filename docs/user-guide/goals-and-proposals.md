# 安排、目标与主动关注

安排页展示任务、目标、日程及主动关注。可以在聊天中让模型建立或取消日程、定时器或相应工作，由管理工具实际落实；需要授权时仍在原任务核对确认。

“关注”是后台记录的检查机会，包含事项、依据、时间和处理状态，不是逐条等待你接受的提议待办。事件、计划复查、交流机会和低频整理触发有界检查，模型判断是否需要联系你；不需要时可以安静结束。

普通主动聊天统一经过 AgentCore，可以使用被程序允许的工具，不能凭角色性格扩大权限。确定的日程提醒按调度履约，不必再由模型批准。主动内容标为助手发起，不伪造你说过的话。

通知快捷菜单或聊天要求可以分别暂停主动聊天和提醒；暂停不删除日程、取消任务或修改系统权限，恢复也不补弹所有积压通知。任务执行的暂停/继续是另一项功能，见[任务说明](tasks-and-permissions.md)。

旧版本仍有 proposal 管理兼容接口，不作为当前主动关注的用户流程。后台只运行当前角色，切换到其他角色后不会继续原角色的主动行为。
